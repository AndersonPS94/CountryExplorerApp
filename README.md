# 🌍 CountryExplorerApp

Uma aplicação Android moderna e reativa, desenvolvida em Kotlin, que permite explorar informações detalhadas sobre países de todo o mundo.

## 🎯 Objetivo e Principais Funcionalidades

O **CountryExplorerApp** foi criado como um projeto de estudo e demonstração das melhores práticas de desenvolvimento Android contemporâneo, utilizando a arquitetura MVVM/Clean Architecture e a biblioteca Jetpack Compose para a construção da UI.

### ✨ Funcionalidades

* **Listagem de Países:** Visualização de uma lista completa de países.
* **Busca:** Funcionalidade de pesquisa para filtrar países por nome.
* **Detalhes do País:** Ao selecionar um país, o usuário é direcionado a uma tela com informações detalhadas (bandeira, capital, população, moedas, idiomas, etc.).
* **Tratamento de Estado:** Gerenciamento robusto de estados (carregamento, dados, erro) e conectividade.

## 🛠️ Tecnologias e Bibliotecas Utilizadas

| Categoria | Tecnologia/Biblioteca | Propósito |
| :--- | :--- | :--- |
| **Linguagem** | **Kotlin** | Linguagem de programação moderna e oficial para o Android. |
| **UI** | **Jetpack Compose** | Toolkit declarativo para construção nativa da UI. |
| **Arquitetura** | **MVVM/Clean Architecture** | Separação de responsabilidades e testabilidade. |
| **Rede** | **Retrofit** & **OkHttp** | Cliente HTTP para chamadas REST à API externa. |
| **Assincronismo** | **Kotlin Coroutines** | Gerenciamento de operações assíncronas e concorrentes. |
| **Imagens** | **Coil** | Carregamento e cache de imagens otimizado para Compose. |
| **Navegação** | **Compose Navigation** | Gerenciamento da navegação entre telas no Compose. |

## 🚀 Como Executar o Projeto Localmente

Siga os passos abaixo para clonar e rodar o projeto em sua máquina local:

1.  **Pré-requisitos:** Certifique-se de ter o **Android Studio (versão Electric Eel ou superior)** instalado com o SDK do Android configurado.
2.  **Clone o Repositório:**
    ```bash
    git clone [https://github.com/AndersonPS94/CountryExplorerApp.git](https://github.com/AndersonPS94/CountryExplorerApp.git)
    ```
3.  **Abra no Android Studio:**
    * No Android Studio, clique em `File` > `Open...` e selecione a pasta `CountryExplorerApp`.
4.  **Sincronize o Gradle:**
    * Aguarde o Android Studio sincronizar o projeto (pode levar alguns minutos na primeira vez).
5.  **Configure o Emulador/Dispositivo:**
    * Selecione um emulador (AVD) ou conecte um dispositivo físico.
6.  **Execute:**
    * Clique no botão **Run** (ícone de play verde) na barra de ferramentas.
